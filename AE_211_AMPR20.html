💡 Conceptos clave que DEBES poder explicar

📐 Soporte y Confianza (Apriori)

Soporte = ¿con qué frecuencia aparece esta combinación en el dataset? Confianza = si ocurre A, ¿con qué probabilidad ocurre B? Son los umbrales que tú fijas: demasiado altos → pocas reglas; demasiado bajos → ruido.

📐 Distancia en K-Means

K-Means agrupa asignando cada instancia al centroide más cercano. El valor de k (número de grupos) lo decides tú: demasiado pequeño → grupos muy heterogéneos; demasiado grande → grupos sin sentido de negocio.

📐 Exactitud, Precisión, Recall y F1

En clasificación, la exactitud (accuracy) sola puede engañarte si las clases están desbalanceadas. La matriz de confusión te revela cuántos falsos positivos y falsos negativos comete el modelo.

🚨 Concepto crítico: Fuga de Datos (Data Leakage)

Ocurre cuando incluyes en el modelo información que no estaría disponible en la vida real al momento de hacer una predicción. Ejemplo clásico: incluir id_paciente como atributo predictivo. El modelo aprenderá a "reconocer" IDs del entrenamiento y obtendrá métricas perfectas, pero fallará completamente con pacientes nuevos. Otras fuentes de leakage en este dataset: fecha_consulta (el número de hospitalizaciones puede variar por temporada, pero la fecha del historial no predice pacientes futuros). Regla de oro: si una columna solo existe porque el evento ya ocurrió, o es un identificador único, descártala antes de modelar.

🧩 Esqueleto de referencia — Pipeline mínimo en Python

Este pseudocódigo te muestra la estructura. Tú decides qué dataset y qué algoritmo usar dentro de cada bloque marcado con # ← TU CÓDIGO.

# ──────────────────────────────────────────────────────────────
# PIPELINE MÍNIMO AMPR-20 — Actividad de Evaluación 2.1.1
# Google Colab · Python 3
# ──────────────────────────────────────────────────────────────

# 1. IMPORTAR LIBRERÍAS  ───────────────────────────────────────
import pandas as pd
import numpy as np
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix
import matplotlib.pyplot as plt
import seaborn as sns

# 2. CARGAR EL DATASET  ───────────────────────────────────────
# ← Sustituye la ruta por tu archivo real
df = pd.read_csv('mi_dataset.csv')
print(df.head())            # Captura de pantalla obligatoria ①
print(df.info())            # Tipos de datos y valores nulos
print(df.describe())        # Estadísticos básicos

# 3. DIAGNÓSTICO PREVIO — EJECUTAR SIEMPRE ANTES DE LIMPIAR ──
print(f"Filas antes de limpiar: {len(df)}")   # ¿Cuántos registros tienes?
print("\nNulos por columna:")
print(df.isnull().sum().sort_values(ascending=False))  # Captura ① — radiografía de calidad
print(f"\nDuplicados: {df.duplicated().sum()}")   # ¿Hay filas repetidas?
print(f"\nValores únicos en variable objetivo:")
print(df['nombre_columna_objetivo'].value_counts())  # ← ¿Más de 2 clases? Problema de estandarización

# 3b. LIMPIEZA PASO A PASO (no usar dropna() directo sin revisar)
# ⚠️ TRAMPA FRECUENTE: df.dropna() elimina TODAS las filas con
#    CUALQUIER nulo. En este dataset, eso puede borrar >80% de tus datos.
#    Decide columna por columna: ¿eliminar, imputar con media/moda,
#    o dejar el nulo y manejarlo después?
df = df.dropna(subset=['col_importante_1', 'col_importante_2'])  # ← Solo columnas críticas
print(f"Filas tras limpiar: {len(df)}")    # Verifica que no perdiste demasiado

# 3c. ESTANDARIZAR VARIABLE OBJETIVO ─────────────────────────
# ⚠️ Si tu columna objetivo mezcla "Sí", 1, "True", "INGRESADO"…
#    sklearn la tratará como 8 clases distintas, no como binaria.
#    Mapea todo a 0/1 antes de continuar:
positivos = ['Sí', 'SI', 'si', '1', 'True', 'INGRESADO']
df['nombre_columna_objetivo'] = df['nombre_columna_objetivo'].astype(str).str.strip()
df['nombre_columna_objetivo'] = df['nombre_columna_objetivo'].apply(lambda x: 1 if x in positivos else 0)
print(df['nombre_columna_objetivo'].value_counts())   # Debe mostrar solo 0 y 1

# 3d. CODIFICAR CATEGÓRICAS y DESCARTAR COLUMNAS NO PREDICTIVAS
# ⚠️ FUGA DE DATOS (Data Leakage): id_paciente y fecha_consulta
#    NO deben entrar al modelo. Un ID único "predice" perfectamente
#    pero es información que no existirá con pacientes nuevos.
df = df.drop(columns=['id_paciente', 'fecha_consulta'])   # ← Eliminar antes de codificar
df = pd.get_dummies(df, drop_first=True)               # ← Convierte texto a números
# ← Normalizar si el algoritmo lo requiere (StandardScaler)

# 4. SEPARAR ATRIBUTOS Y CLASE  ───────────────────────────────
X = df.drop(columns=['nombre_columna_objetivo'])   # ← TU COLUMNA META
y = df['nombre_columna_objetivo']

# 5. DIVIDIR EN ENTRENAMIENTO Y PRUEBA  ────────────────────────
# test_size=0.3 → 70% entrenamiento, 30% prueba (estándar)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)

# 6. SELECCIÓN DE ATRIBUTOS (opcional, pero suma puntos)  ──────
from sklearn.feature_selection import SelectKBest, chi2
selector = SelectKBest(chi2, k=5)   # ← Elige k según tu análisis
X_train = selector.fit_transform(X_train, y_train)
X_test  = selector.transform(X_test)
print("Atributos seleccionados:", selector.get_support(indices=True))

# 7. MODELO PRINCIPAL  ────────────────────────────────────────
# ← REEMPLAZA con tu algoritmo elegido y argumentado:
from sklearn.tree import DecisionTreeClassifier   # ejemplo
modelo = DecisionTreeClassifier(max_depth=5, random_state=42)
modelo.fit(X_train, y_train)
y_pred = modelo.predict(X_test)

# 8. EVALUACIÓN DEL MODELO PRINCIPAL  ─────────────────────────
print("Exactitud:", accuracy_score(y_test, y_pred))   # Captura ②
print(classification_report(y_test, y_pred))
cm = confusion_matrix(y_test, y_pred)
sns.heatmap(cm, annot=True, fmt='d', cmap='Blues')     # Captura ③
plt.title('Matriz de Confusión — Modelo Principal')
plt.show()

# 9. MODELO DE COMPARACIÓN (verificación de confiabilidad)  ───
from sklearn.naive_bayes import GaussianNB          # ejemplo alterno
modelo2 = GaussianNB()
modelo2.fit(X_train, y_train)
y_pred2 = modelo2.predict(X_test)
print("Exactitud modelo 2:", accuracy_score(y_test, y_pred2))  # Captura ④

# 10. CONCLUSIÓN COMPARATIVA  ─────────────────────────────────
# ← Escribe aquí en texto Markdown (celda de texto en Colab)
# por qué uno supera al otro en este contexto específico.
# Eso es lo que evalúa la rúbrica en "Evaluación del modelo".

🛑 Errores comunes en esta actividad

⚠️

Confundir exactitud con confiabilidad

Obtener 95% de accuracy y declararlo "excelente" sin revisar si las clases están desbalanceadas. Un modelo que siempre predice la clase mayoritaria puede tener 95% con un F1 desastroso. Siempre revisa el classification report completo.

⚠️

Argumentar el modelo con palabras genéricas

"Elegí el Árbol de decisión porque es fácil de entender." Eso es insuficiente. La rúbrica pide argumentar en función del tipo de datos, el objetivo y el problema de negocio específico.

⚠️

Usar el dataset de entrenamiento para evaluar

Si evalúas el modelo con los mismos datos con que lo entrenaste, obtendrás métricas irrealmente altas (overfitting). Verifica que usas X_test / y_test en la función de evaluación, no X_train.

⚠️

Copiar el código del esqueleto sin adaptarlo

El esqueleto usa nombres genéricos como 'nombre_columna_objetivo'. Si tu notebook contiene ese texto literal, la IA o el docente sabe que no lo leíste. Sustitúyelo por los nombres reales de tu dataset.

🔴

ValueError: could not convert string to float — columnas categóricas sin codificar

sklearn no acepta texto como entrada. Si ves este error, significa que pasaste columnas como genero, municipio o actividad_fisica directamente al modelo sin convertirlas a números.
Solución: aplica pd.get_dummies(df, drop_first=True) sobre el DataFrame antes de separar X e y. Además, elimina siempre las columnas que causan fuga de datos (Data Leakage): id_paciente y fecha_consulta tienen información única por paciente que el modelo "memoriza" pero que no existirá con pacientes nuevos.

🔴

Variable objetivo multiclase por accidente — mezcla de "Sí", 1, "True", "INGRESADO"…

Si no estandarizas la columna hospitalizacion antes del modelado, sklearn detectará hasta 10 "clases" distintas en lugar de una clasificación binaria (0/1). El modelo "funcionará" técnicamente, pero sus métricas no tendrán sentido para tu problema de negocio.
Diagnóstico: ejecuta df['hospitalizacion'].value_counts() — si ves más de 2 filas, tienes el problema. Usa un mapeo explícito a 0/1 antes de continuar.

📖 Glosario

Clasificación
Modelo supervisado que asigna una categoría discreta a instancias nuevas basándose en datos históricos etiquetados.
Clúster (Agrupamiento)
Modelo no supervisado que descubre grupos naturales en los datos sin etiquetas previas, minimizando la varianza intra-grupo.
Reglas de Asociación
Técnica que encuentra combinaciones frecuentes de ítems en transacciones. Soporte: frecuencia de la combinación. Confianza: probabilidad condicional.
Selección de Atributos
Proceso de identificar las variables más relevantes para el objetivo, eliminando ruido e información redundante.
Matriz de Confusión
Tabla que muestra Verdaderos/Falsos Positivos y Negativos. Permite calcular Precisión, Recall y F1-Score.
Overfitting (Sobreajuste)
El modelo "memoriza" el dataset de entrenamiento y falla con datos nuevos. Se detecta comparando accuracy en train vs test.
CRISP-DM
Metodología estándar para análisis predictivo: Comprensión del negocio → Comprensión de datos → Preparación → Modelado → Evaluación → Implantación.
Trade-off
Compromiso entre dos propiedades deseables que no se pueden maximizar simultáneamente (ej. precisión vs interpretabilidad de un modelo).
Diálogo Socrático con IA
Técnica de aprendizaje donde la IA guía con preguntas en lugar de dar respuestas, activando el razonamiento propio del estudiante.
Aprendizaje Supervisado
El modelo aprende de ejemplos etiquetados (con la respuesta correcta). Requiere una variable objetivo explícita en el dataset.
Hiperparámetro
Parámetro de configuración del algoritmo que tú defines antes del entrenamiento (ej. max_depth en un árbol, k en K-Means).
Agencia Compartida
Principio pedagógico: tú (estudiante) tomas las decisiones de diseño; la IA te apoya con preguntas y opciones, pero no decide por ti.
